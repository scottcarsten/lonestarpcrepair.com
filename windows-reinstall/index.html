Service

Windows repair and reinstall

When Windows will not start or keeps crashing, we repair it. When it is too far gone to patch, a clean install is the honest fix. Your files get saved first.

When it makes sense

  • Windows will not start or keeps crashing
  • A bad infection left the system messy
  • The computer is slow and nothing else helped
  • You are passing the computer to someone else

How it goes

  1. You call and describe what Windows is doing.
  2. We copy your files off first and check the copy.
  3. We repair Windows, or install a clean copy and the updates if that is the better fix.
  4. We put your files back and set up your printer, email and browser.
  5. You are back up and running.

Good to know

You will need your own Microsoft account password, and any program installers or license keys you have. Call if you are not sure. We can usually find what is needed.
