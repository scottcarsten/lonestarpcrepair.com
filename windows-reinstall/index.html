Windows reinstall

When Windows is too far gone to patch, a clean install is the honest fix. Your files get saved first.

When a reinstall makes sense

  • Windows will not start or keeps crashing
  • A bad infection left the system messy
  • The computer is slow and nothing else helped
  • You are passing the computer to someone else

How it goes

  1. Scott picks up the computer.
  2. He copies your files off first and checks the copy.
  3. He installs a clean Windows and the updates.
  4. He puts your files back and sets up your printer, email and browser.
  5. You schedule the return and pay when it is back.

Good to know

You will need your own Microsoft account password, and any program installers or license keys you have. Call if you are not sure. Scott can usually find what is needed.
