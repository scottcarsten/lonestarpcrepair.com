# lonestarpcrepair.com

Static site for Lone Star PC Repair, hosted on GitHub Pages behind Cloudflare.
Plain HTML, CSS and a little vanilla JS. No frameworks, no build step, no third party requests.

Every page uses root absolute paths, one shared header and one shared footer (copied into each page by hand), a meta CSP with no `unsafe-inline`, LocalBusiness plus ProfessionalService JSON-LD (no street address), and system font stacks only.
The logo source is in `/workspace/gotham-shared/brand/lonestarpcrepair/`.

## Landing pages

Six search-term pages (five error phrases plus custom PowerShell scripts for small business), one per error phrase, each with the term in title, H1, opening line and meta description, one call to action (free sample check, contact link, tel link, repeated at the bottom), Service and FAQPage JSON-LD, and a link to Data Rescue. Data Rescue and the home page link back to all five. Reasoning and evidence are in `/workspace/gotham-shared/ops/seo/2026-11-04_pcrepair-top5-terms.md` (not published). The pages are generated by `/workspace/gotham-shared/ops/seo/build_pcrepair_landing_pages.py REPO_DIR`; after edits to the generated pages, change the script and re-run it, or edit the HTML by hand and stop using the script. New pages must be added to `sitemap.xml`.

## Privacy wording

Every page says: files are handled privately and never shared, and all client data is automatically deleted and securely wiped 30 days after delivery. Keep that sentence identical everywhere. Never say where files are stored: no vendor or cloud names.

## Rules for copy

No prices, quotes only. Fort Worth area only, no street address. Only phone is 817-242-4941. No email address on the site. No em or en dashes, no parentheses in visible copy, no legacy desktop database brands we do not advertise, no certs we do not claim. Nothing auto replies to anyone.
