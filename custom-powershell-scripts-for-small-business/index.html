What a script can do for you

Most small offices have a few jobs that someone does by hand every week. Setting up a new hire, removing a leaver, checking who has which license, cleaning up a shared folder, pulling the same report.

A custom PowerShell script does the job the same way every time, and it can run on a schedule so nobody has to remember.

Chores that suit a script

  • Onboarding and offboarding: accounts, mailboxes, groups and licenses set up the same way every time.
  • Microsoft 365 chores: shared mailboxes, license reports, inactive account lists.
  • File chores: cleanup of old files, renaming in bulk, copying to a backup folder.
  • Reports: a plain spreadsheet or page that lands where you want it, on a schedule.
