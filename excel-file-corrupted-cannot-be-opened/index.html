What is going on

You open a workbook and Excel says the file is corrupted and cannot be opened. Other versions of the message say Excel found unreadable content or cannot open the file because the format or extension is not valid.

An .xlsx file is a package of many small parts, so one bad part can block the whole file even when most of it is fine.

What usually causes it

  • Excel or the computer crashed while the file was saving.
  • The file was copied or downloaded and the transfer was cut short.
  • A USB stick, a network drive or a sync tool damaged the file.
  • The file was renamed to a different extension, or a macro or add in broke the workbook.

What to do first

  1. Copy the file first and work on the copy.
  2. In Excel choose File, then Open, pick the file, click the arrow beside the Open button and choose Open and Repair.
  3. Look for an earlier version in file history or in a backup.
  4. If Open and Repair fails, send me a sample.
